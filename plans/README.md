# plans/ — технические планы реализации

Эта папка содержит технические планы разработки функций LogistiCRM.

## Правила работы с планами

1. **Один план = одна функция.** Каждая новая функция получает отдельный файл плана.
2. **Формат имени файла:** `YYYY-MM-DD-название-функции.md`
3. **Структура плана:** делится на фазы. У каждой фазы статус `[ ]` (не сделано) или `[x]` (сделано).
4. **Итоговый блок:** в конце каждого плана указано — реализован целиком или нет, что осталось.
5. **Актуализация:** любой агент, работающий с планом, обязан его обновлять — отмечать выполненные фазы, дописывать что сделал.

## Пример структуры плана

```markdown
# 2025-01-15-landing-page.md

## Фазы

- [x] Фаза 1: Структура и дизайн
- [ ] Фаза 2: Разработка компонентов
- [ ] Фаза 3: Интеграция с формой захвата

## Итог

Реализовано: фаза 1
Осталось: фазы 2-3
```
